----------------------------------------------------------------------
PART 1: ERRORS IN CONTROL STATEMENTS (IF, WHILE, RETURN)
----------------------------------------------------------------------

1. Error: "the if condition must be a scalar value"
   Cause: The condition inside the 'if' statement must be a scalar type, not a structure.
   Code to insert in function h:
       if (a) { int x = 1; }

2. Error: "the while condition must be a scalar value"
   Cause: The condition inside the 'while' statement must be a scalar type, not a structure.
   Code to insert in function h:
       while (a) { int x = 1; }

3. Error: "a void function cannot return a value"
   Cause: A function with a void return type cannot return any value.
   Code to insert in function f (at the end):
       return 42;

4. Error: "the return value must be a scalar value"
   Cause: The expression returned by a non-void function must evaluate to a scalar.
   Code to insert in function h (at the end):
       return a;

5. Error: "cannot convert the return expression type to the function return type"
   Cause: The type of the return expression cannot be converted to the function's return type.
   Code to insert in function h (at the end):
       return text;


----------------------------------------------------------------------
PART 2: ERRORS IN ASSIGNMENT OPERATIONS (=)
----------------------------------------------------------------------

6. Error: "the assign destination must be a left-value"
   Cause: The left side of an assignment must be an lval (left-value).
   Code to insert in function f or h:
       1 = x;

7. Error: "the assign destination cannot be constant"
   Cause: The destination of an assignment cannot be a constant value.
   Code to insert in function f or h:
       "test"[0] = 'a';

8. Error: "the assign destination must be scalar"
   Cause: The assignment destination (left side) must be a scalar, not a structure.
   Code to insert in function f or h:
       a = x;

9. Error: "the assign source must be scalar"
   Cause: The assignment source (right side) must be a scalar, not a structure.
   Code to insert in function f or h:
       x = a;

10. Error: "the assign source cannot be converted to destination"
    Cause: The type of the source expression cannot be converted to the destination type.
    Code to insert in function f or h:
        x = f;


----------------------------------------------------------------------
PART 3: ERRORS IN ARITHMETIC AND LOGICAL OPERATORS
----------------------------------------------------------------------

11. Error: "invalid operand type for ||"
    Cause: Both operands for the logical OR operator must be scalar types and cannot be structures.
    Code to insert in function h:
        if (x || a) { int v = 1; }

12. Error: "invalid operand type for &&"
    Cause: Both operands for the logical AND operator must be scalar types and cannot be structures.
    Code to insert in function h:
        if (a && y) { int v = 1; }

13. Error: "invalid operand type for == or !="
    Cause: Both operands for equality/inequality must be scalar types and cannot be structures.
    Code to insert in function h:
        if (a == v[0]) { int v = 1; }

14. Error: "invalid operand type for  , <="
    Cause: Both operands for relational operators (<, <=, >, >=) must be scalar types and cannot be structures.
    Code to insert in function h:
        if (a > y) { int v = 1; }

15. Error: "invalid operand type foror"
    Cause: Addition or subtraction operators do not accept structures or arrays as operands.
    Code to insert in function f or h:
        x = y + a;

16. Error: "invalid operand type for or /"
    Cause: Multiplication or division operators do not accept structures or arrays as operands.
    Code to insert in function f or h:
        x = y * a;


----------------------------------------------------------------------
PART 4: ERRORS IN TYPE CASTING (EXPRCAST)
----------------------------------------------------------------------

17. Error: "cannot convert to a struct type"
    Cause: Attempting to cast a value to a structure type is strictly prohibited.
    Code to insert in function f or h:
        x = (struct S)y;

18. Error: "cannot convert a struct"
    Cause: A structure type cannot be cast or converted into another type.
    Code to insert in function f or h:
        x = (int)a;

19. Error: "an array can be converted only to another array"
    Cause: An array expression cannot be explicitly cast to a non-array/scalar type.
    Code to insert in function h:
        x = (int)text;

20. Error: "a scalar can be converted only to another scalar"
    Cause: A scalar type cannot be cast or converted into an array type.
    Code to insert in function f or h:
        text = (char[])x;


----------------------------------------------------------------------
PART 5: ERRORS IN UNARY AND POSTFIX OPERATORS (INDEXING, STRUCT FIELDS)
----------------------------------------------------------------------

21. Error: "unary or! must have a scalar operand"
    Cause: Unary minus (-) or logical NOT (!) requires a scalar operand.
    Code to insert in function f or h:
        x = -a;

22. Error: "only an array can be indexed"
    Cause: Attempting to use array indexing brackets on a variable that is not an array.
    Code to insert in function f (replace text[i] with ch[i]):
        ch[i] = '#';

23. Error: "the index is not convertible to int"
    Cause: The index expression used inside the brackets must be convertible to an integer.
    Code to insert in function f:
        text[a] = '#';

24. Error: "a field can only be selected from a struct"
    Cause: The dot operator (.) can only be applied to variables of a struct type.
    Code to insert in function f or h:
        x.n = 5;

25. Error: "the structure %s does not have a field %s"
    Cause: The field name specified after the dot operator (.) does not exist in the struct definition.
    Code to insert in function h:
        a.age = 20;


----------------------------------------------------------------------
PART 6: ERRORS IN FUNCTION CALLS & PRIMARY EXPRESSIONS
----------------------------------------------------------------------

26. Error: "undefined id: %s"
    Cause: The identifier used does not exist in the symbol table.
    Code to insert in function f or h:
        nonExistentFunction();

27. Error: "only a function can be called"
    Cause: Attempting to use function call parentheses () on an identifier that is not a function.
    Code to insert in function f or h:
        x();

28. Error: "too many arguments in function call"
    Cause: The number of arguments passed in the call exceeds the number of parameters defined by the function.
    Code to insert in function h:
        f(text, y, '#', 100);

29. Error: "in call, cannot convert the argument type to the parameter type"
    Cause: The data type of the passed argument cannot be converted to the required parameter type.
    Code to insert in function h:
        f(a, y, '#');

30. Error: "too few arguments in function call"
    Cause: The number of arguments passed in the call is less than the number of parameters defined.
    Code to insert in function h:
        f(text, y);

31. Error: "a function can only be called"
    Cause: A function name is referenced on its own in an expression without parentheses.
    Code to insert in function f or h:
        x = f;
